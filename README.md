# Triplettes

This game is a player-vs-computer implementation of the Kaya Miyano game commercialized as trio, Nano, or Slotters.

One player, a few computer opponents, and a 36-card deck. Be the first to collect three matching sets, or the 7s.

## Run

```sh
npm install
npm run dev
```

Open the address Vite prints. The menu covers language, theme, speed, the rules, and a new game.
